# Achillea
## Platform
Mobile-first web application.
## Stack
React, TypeScript, Vite, Vercel Node functions and the existing Tiger Data PostgreSQL schema.
## Users and purpose
Demo nurses review assigned synthetic L&D patients, document bedside care, and switch to a separate ICU expansion scenario for dual-region movement review.
## Constraints
Educational synthetic demo only. The external simulator owns observation generation and processing. Achillea displays stored evidence and manages explicit nurse workflows. Movement never verifies care. Private demo sessions protect access; hospital identity, physical-device validation, EHR integration and clinical use remain outside scope.
